**実装状態：本書はLINE管理画面の構築指示であり、設定完了の証明ではありません。** 最新の接続状況と引継ぎ項目は [LINE引継ぎチェックリスト](line-handoff-status.md) を正本とします。UTAGE公開登録URLはLPに設定済み。LIFF ID・自動応答・外部案件管理の稼働は未確認です。

## ゴールとCV定義

- LINE友だち追加: マイクロCV
- 「相談を始める」または具体的な相談文の送信: 問い合わせCV
- 対応地域・希望用途または具体的な悩み・検討意思・連絡可能性を確認: 有効相談
- 必要な写真または図面と設置条件がそろう: 提案準備完了
- 現地調査日時の確定: 商談化
- 正式見積もり提出: 見積もり化

### 友だち追加直後の挨拶

```text
友だち追加ありがとうございます。
plus wood deckです。

商品やサイズが決まっていなくても大丈夫です。
庭で困っていることと、どんなふうに使いたいかから一緒に整理します。

まずは下の「相談を始める」をタップしてください。
写真や図面は後からでも送れます。
```

### 最初の問い合わせを確定するメッセージ

リッチメニューの「相談を始める」は、テキストメッセージ `ウッドデッキの相談を始める` を送る設定にする。

このメッセージ受信時のアクション:

1. ラベル `相談_開始` を付与。
2. 流入経路ラベルを維持。
3. 相談開始日時を記録。
4. 下記の質問を自動返信。
5. 管理用スプレッドシートへ `line_user_id / 相談開始日時 / 流入経路 / consult_id / 状態` を追記。

### 自動返信1

以下の返信1〜3は、該当項目がまだ届いていない場合のみ送ります。LPから届く定型文の「施工希望地域」「いま困っていること」「庭でしたいこと」「気になる形」「広さの参考」「価格診断の商品」を先に読み取り、確認済みの項目は飛ばしてください。開始メッセージだけと具体的な相談文は別集計します。

```text
ありがとうございます。ここからお問い合わせ受付です。

まず、お住まいの市区町村を教えてください。
例：福岡市、名古屋市、横浜市
```

### 自動返信2（市区町村回答後）

```text
庭で一番近いお悩みを、番号で教えてください。

1. 庭へ出る段差が大きい
2. 洗濯物を運びにくい
3. 庭が狭く、置けるか不安
4. 道路・隣家の視線が気になる
5. 家族で過ごす場所がほしい
6. 費用の目安を知りたい
7. まだ決まっていない
```

### 自動返信3（悩み回答後）

```text
分かる範囲で、次の写真を送ってください。

① 家の中から庭を見た写真
② 庭から窓・外壁を見た写真
③ 庭全体が分かる写真

図面をお持ちの場合は一緒に送れます。
撮り方が難しい場合は「写真は後で」と送ってください。
```

有効相談の条件を確認した時点で `相談_有効` を付与する。写真または図面受信時に `相談_写真待ち` を外し、案件の写真受領欄と提案準備状況を更新する。写真未提出だけを理由に相談を無効としない。

## 問い合わせ記録

最小構成はUTAGE内のラベルとGoogleスプレッドシート追記を併用する。

推奨列:

```text
consult_id, line_user_id, first_contact_at, source, campaign,
city, pain, intended_use, product, width, depth, height,
reference_price_min, reference_price_max, has_photo, has_plan,
status, assignee, site_visit_at, quote_at, won_at, lost_reason
```

`consult_id` が相談文に含まれる場合は同一相談として更新する。存在しない場合は、LINEユーザーID＋初回送信日時で仮IDを発行する。

## 運用ルール

- AIは提案候補と確認事項を整理する。施工可否・構造・正式価格を断定しない。
- 対応エリアは福岡・九州、東海、関東。市区町村入力後に加盟店の対応可否を確認する。
- 画像・図面は個人情報として扱い、利用目的と保存期間を案内する。
- 24時間以上回答が止まった場合のみ1回フォロー。配信停止意思があれば即時停止。
- `相談_有効` 以降はスタッフ通知と引き継ぎを優先する。

## 外部設定前テスト

1. 新規友だち追加で挨拶が1通だけ届く。
2. 「相談を始める」で `相談_開始` が付く。
3. 同じメッセージを再送してもスプレッドシートに重複行を作らない。
4. 画像受信で `has_photo=true` になる。
5. スタッフ希望で自動質問を停止する。
6. 本体価格リンクがHTTPSで正しい商品一覧を開く。
7. iPhone/Android両方で4領域が誤タップしない。
