# LP視覚説明用・生成画像プロンプト

2026-09-28に、スマートフォンLPの説明力を上げる目的で組み込んだ画像の制作仕様です。すべて画像生成ツールの標準モードで生成し、LP内では「生成画像」「イメージ」であることを明示します。

## 1. 2人でお茶をする広さ

- 用途：相談で整理できる内容の完成イメージ
- 場面：日本の一般的な戸建て住宅。リビングの掃き出し窓から直接つながる約2.7m×1.8mの検討例に近いコンパクトデッキ
- 必須要素：椅子2脚、小さな丸テーブル、40代程度の日本人2名、庭へ降りるステップ、地面と住宅外壁
- 画角：少し高い位置からの3:2横位置。家具と人が動く余白が分かる
- 制約：豪邸・海外住宅・ブランド・文字・透かし・過度な演出を避ける

## 2. 洗濯動線

- 用途：悩み選択と相談モデル「洗濯動線を短くしたい」
- 場面：日本の一般的な戸建て住宅。室内から掃き出し窓、デッキ、屋外物干しまでを一画面に収める
- 必須要素：洗濯かごを持つ日本人の成人、段差の小さい出入口、歩けるデッキ奥行き、物干し
- 画角：目線の高さの3:2横位置。移動経路が追える構図
- 制約：豪邸・広告的なポーズ・海外住宅・ブランド・文字・透かし・不自然な構造を避ける

## 3. 狭い庭に合わせる変形デッキ

- 用途：悩み選択と相談モデル「狭い庭を使える場所にしたい」
- 場面：日本の一般的な戸建て住宅の細長い側庭
- 必須要素：L字または角を調整したデッキ、残した通路、室外機と点検スペース、排水、必要方向だけの縦格子目隠し
- 画角：少し高い位置からの3:2横位置。デッキ形状と通路が同時に分かる
- 制約：広い庭・豪邸・海外住宅・ブランド・文字・透かし・不可能な納まりを避ける

## 4. 人工木と天然木の比較

- 用途：素材比較セクション
- 場面：明るいアイボリーの打ち合わせテーブル
- 必須要素：同じ大きさで並ぶ濃いブラウンの人工木サンプルと明るい天然木サンプル、木目・端部・手触りが分かる成人の手
- 画角：斜め上からの3:2横位置。左右を同じ比重で扱う
- 制約：優劣を演出しない。ブランド・文字・透かし・プラスチック感・過度な欠点を避ける
